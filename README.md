# defeat.vn

Website DEFEAT — gia công phần mềm, giải pháp & mã nguồn.

**Stack:** Astro 7.4 · React 19 (islands) · Tailwind CSS 4 + daisyUI 5 · MDX · Cloudflare Workers

```bash
npm install
npm run dev
```

- Kiến trúc, chiến lược render (SSG/SSR/ISR/CSR), SEO: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Lựa chọn công nghệ & phiên bản: [`docs/TECH_STACK.md`](docs/TECH_STACK.md)

Yêu cầu Node 26 LTS (tối thiểu 22.23.4, xem `.nvmrc`).
