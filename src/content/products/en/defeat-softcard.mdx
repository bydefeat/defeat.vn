## Overview

**DEFEAT Softcard** is a complete source code package for running a prepaid card business: **card-to-cash exchange**, **digital code sales**, **mobile and game top-ups**, plus member wallets, bank deposits/withdrawals and an API for resellers. Every transaction runs automatically 24/7, from the customer's request and provider selection to crediting the wallet or delivering the code.

It is built from scratch on Next.js 16 and PostgreSQL, with separate customer, partner API and admin areas. You own the code and run it on your own server, with no third-party lock-in.

## Supported cards and services

The catalog is configured in the admin: enable or disable each telco, issuer and denomination.

- **Mobile cards:** Viettel, Vinaphone, Mobifone, Vietnamobile.
- **Game cards:** Garena, Zing, Vcoin, Gate, Appota, Funcard, SohaCoin, Kul, Carot...
- **Software:** licence keys such as Kaspersky and other digital products.
- **Denominations:** standard 10,000đ – 1,000,000đ, game cards up to 5,000,000đ, plus a small-denomination set.

## Core capabilities

### Card exchange

- Submit one card or many at once, on the web or via API.
- Public fee table by **member tier** and denomination.
- Handles wrong denominations, invalid and pending cards; re-checks stuck cards and resubmits when a provider loses them.
- Flags and rejects suspicious transactions, locks connections that keep sending invalid cards.
- Profit reports by channel, telco and provider.

### Digital code store

- Catalog of mobile, game and software codes by issuer and denomination.
- Multi-item cart, quick quantity picks, per-product discounts, pay by wallet balance or bank transfer.
- Delivers from **imported stock** (Excel) or buys instantly from providers; automatic refunds on failed orders.
- Bank-transfer orders are delivered as soon as the payment is matched.

### Mobile and game top-ups

- Prepaid/postpaid mobile and game top-ups with product-specific forms.
- Single, bulk and quick orders with clear statuses for customers.
- Categories, products and package options managed in the admin.

### Providers and routing

- Multiple providers per service with scheduled fee syncing.
- Four routing strategies: **in order**, **by ratio**, **cheapest first**, **round-robin**.
- Automatic failover to the next provider; when none is left, reject or hand over to manual processing.
- Fees, margins and limits per channel and customer group, with optional automatic margins based on provider fees.

### Wallets, payments and reconciliation

- Member wallets: deposits, withdrawals, internal transfers, transfer fees, balance history.
- **Local bank** (VCB, MB, ACB, TCB...) and **e-wallet** (MoMo, ZaloPay, ViettelPay) gateways.
- **Automatic bank matching** of incoming transfers to invoices and card orders by reference; expired invoices are cancelled automatically.
- Daily limits for code purchases, deposits, withdrawals and transfers.
- Referral commissions paid out automatically after a holding period.

### Partner and developer API

- Customers create their own API connections: services, Callback URL, GET/POST, IP allowlist.
- New connections can be enabled automatically after a set delay once they qualify (Callback and IP set).
- API docs with navigation, examples and error codes, plus a **Sandbox** with sample cards for every case, testable in the browser.

### Security

- Two-factor confirmation: email OTP, Google Authenticator or a secondary password for sensitive actions.
- Sign in with Google, Facebook, GitHub, Microsoft... and user identity verification.
- Secret admin path, role-based access control, time-limited IP allow/deny lists, login logs.
- Correct client IP behind Cloudflare, preventing spoofed IPs from bypassing limits.

- Dashboard with today's and this month's revenue and profit per service, plus a pending-task queue.
- **AI Agent access over MCP**: add the site to Claude, ChatGPT and others, sign in once and give instructions in plain language. Agent permissions follow the assigned role and every action is logged.

## Automation

Scheduled jobs with a log for every run and a manual run button:

- Update provider fees and re-order provider chains by fee.
- Check pending cards, resubmit or mark them invalid.
- Sync bank transactions, deliver codes for paid orders, cancel expired invoices.
- Auto-enable qualifying new API connections.
- Pay out referral commissions.

## From request to completed transaction

1. **Choose a service**: exchange, buy codes or top up, on the web or via API.
2. **Validate**: denomination, serial, balance, limits and IP.
3. **Route**: pick a provider by fee and health, fail over on errors.
4. **Complete and reconcile**: credit the wallet or deliver the code, send the callback, record profit.

- A dedicated server (VPS) running Node.js, PostgreSQL and Valkey (Redis-compatible).
